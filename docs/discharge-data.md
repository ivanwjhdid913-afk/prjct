# Подтверждённые сведения о водоотведении Липецка

Дата проверки: **30 октября 2026 года**. Набор: `backend/data/discharges/catalog.v1.json`, версия формата 1. Четыре карточки — это объекты исследования, а не четыре подтверждённых действующих водовыпуска.

Ни один объект пока не имеет полного набора для текущей модели консервативного вещества. В каталоге нет подтверждённых координат выпусков, поэтому маркеры отсутствуют. Ни одна карточка не выбирает участок и не запускает расчёт. Сценарный режим работает независимо.

## Проект запроса недостающих сведений

Этот перечень подготовлен для согласования. Запросы никому не отправлялись.

### Обязательное для первого расчёта

Предпочтительный кандидат на следующий шаг — **ЦОСК РВК**, поскольку есть прямая таблица хлоридов на выходе. Она всё ещё требует нового согласованного набора для одного конкретного периода:

| Что запросить у оператора / профильного ведомства | Единицы, шаг и формат |
|---|---|
| Актуальная ведомость выпусков: ID, действующий/закрытый статус, приёмник, схема связи с очисткой и измерительным створом | CSV/XLSX; статус с датой, адрес и юридический оператор отдельно от выпуска |
| Положение конкретного выпуска и точки отбора проб, погрешность и способ определения | EPSG:4326, долгота/широта в десятичных градусах; GeoJSON Point. Для исходной местной системы — её код и параметры преобразования |
| Геометрия нужного речного участка выше/ниже выпуска, направление течения и связность, поперечные сечения | GeoJSON LineString с CRS EPSG:4326 и явным направлением; сечения/глубины/ширины в метрах, дата съёмки, привязка к пикетажу |
| Расход реки и конкретного выпуска за один выбранный расчётный интервал | м³/с; исходный часовой ряд или более частый доступный шаг, точные timestamps с часовым поясом. Суточные/месячные агрегаты — с правилом усреднения и пропусками |
| Хлориды в стоке и фон выше выпуска, синхронные с расходами | мг/л или исходные мг/дм³; время и место каждой пробы, метод, предел обнаружения, признак ниже предела; CSV. Желательно часовой/суточный ряд согласно программе измерений, без выдуманной интерполяции |
| Режим работы выпуска: интервалы работы, перерывы и изменения нагрузки | timestamps с часовым поясом; журнал событий и исходный шаг, каждый выпуск отдельно |
| Измеренная/обоснованная скорость и коэффициент продольной дисперсии на нужном участке | м/с и м²/с; период, метод определения, диапазон неопределённости; CSV/отчёт со створом |

Пустое значение, отсутствие измерения и значение ниже предела обнаружения должны иметь разные признаки; числом 0 обозначается только измеренный ноль с указанным методом. Для данных в иных единицах сохраняются оригинал, коэффициент и формула преобразования. Проектная мощность, НДС и фактические измерения передаются раздельно. Для концентрации и расхода необходимо указать, один ли это выпуск и совпадают ли периоды.

Для Свободного Сокола сначала запросить разделение хозяйственно-бытовых стоков, передаваемых РВК, и промышленных/ливневых выпусков. Для НЛМК — подтверждение даты и границ закрытия каждого бывшего выпуска; до этого исторический выпуск не считать действующим. Для ЛГЭК/Семёновки — идентификатор сооружений, текущего оператора, приёмника и статус; не объединять с объектом РВК по похожему названию.

## Получение и контроль оригиналов

Полные документы не включены в репозиторий. Явная лицензия на их дальнейшее распространение не установлена. URL, идентификаторы и SHA-256 сохранены в каждой записи `sources` каталога. Для воспроизведения открыть ссылку, сохранить исходный ответ **без перекодирования** и вычислить SHA-256 байтов, например `Get-FileHash -Algorithm SHA256 <путь>`. У HTML нужно сохранять именно HTML указанного URL, а не текст, скриншот или заново экспортированный PDF.

| Документ | SHA-256 сохранённого оригинала |
|---|---|
| KSP, PDF | `55f3b70d9945fdd1fadcdab5aa3325e765b15cb7973acf5f4752e9e27a243065` |
| Схема, печатная с. 46 / HTML 746 | `39a724ecc2a7bc4e84166880e90a5b5c7ff46bc3cc66913a929da62cb66ee605` |
| Схема, печатная с. 47 / HTML 747 | `2d8771291ea58b7cd93d3b87e17dc3d357b3cde9550bda02acd9ae31ec90510e` |
| Пресс-релиз НЛМК | `null`: оригинал прочитан через веб-просмотр; автоматическая загрузка вернула 403, сохранённого оригинала нет |

Контрольные копии и рабочие извлечения находятся только в локальном `.cache/discharge-data/sources/`. SHA фиксирует проверенные байты, но не доказывает истинность утверждения издателя. Изменение страницы при повторном получении требует повторной сверки; хеш пересказа не заменяет хеш оригинала.

## Контракт и проверки

`GET /api/v1/discharge-data` возвращает версионируемый каталог и не использует БД, solver или данные сценариев. API только для чтения. Проверяются полный набор девяти ячеек, допустимые статусы, типы/конечность чисел, координатные границы и назначение координаты, календарные даты/периоды, уникальные идентификаторы и разрешённые ссылки на источники. Ссылки допускают только HTTP(S), без логина/пароля и управляющих символов. Все неизвестные значения явные; отсутствующие числа не получают значения по умолчанию.

Автоматические тесты проверяют отказ при неверных ссылках/датах/числах/матрице, невозможность объявить предприятие водовыпуском или подобрать участок без координат, запрет записи через API и независимость каталога от подключения к БД. Это проверка структуры и прослеживаемости набора, а не подтверждение точности будущего расчёта.
